# 엔티티 인덱스를 작성하기

데이터 모델에 데이터베이스 인덱스를 정의하여 테이블의 여러 행에 걸친 각 속성의 고유성을 보장하거나, 이러한 속성을 필터로 사용하여 검색 속도를 향상시킬 수 있습니다. OutSystems에서는 엔티티 요소 내에서 데이터베이스 인덱스를 모델링할 수 있습니다. 엔티티에 여러 인덱스를 추가하면 데이터베이스 작업(특히 쓰기 작업)의 성능에 부정적인 영향을 미칠 수 있습니다.

데이터베이스 인덱스 생성에 대한 자세한 내용은 [「데이터베이스 인덱스」](https://success.outsystems.com/ja-jp/documentation/11/reference/outsystems_language/data/database_reference/database_indexes/)를 참조하세요.

엔티티 인덱스를 생성하려면 다음 단계를 수행하십시오.

1. 엔티티를 마우스 오른쪽 버튼으로 클릭하고 [**Edit Entity**]를 선택하거나, 엔티티 속성에서 [**Indexes and more**] 버튼을 클릭합니다.
    
    ![Indexes and more 버튼이 강조 표시된 OutSystems의 Edit Entity 대화 상자 스크린샷](https://success.outsystems.com/TK_Resource/0993aa0c-02ab-49fd-8696-5741ed336aaf "Edit Entity Dialog")
    
2. [**New index**] 버튼을 클릭하여 인덱스를 생성합니다.
    
3. 인덱스의 이름을 입력합니다. 이 예시에서는 "**OrderProductUnique**"라고 입력했습니다.
    
4. 이 인덱스를 제한하여 레코드를 한정하려면, **Unique** 속성을 [**Yes**]로 변경합니다.
    
    ![OutSystems에서 새 인덱스에 대한 Unique 속성 토글이 Yes로 설정된 스크린샷](https://success.outsystems.com/TK_Resource/03e268e0-54b1-4235-af8a-622513938db0 "Unique Property Toggle")
    
5. 인덱스에 포함하고 싶은 속성을 추가합니다.
    
    ![OutSystems 플랫폼에서 새 인덱스에 속성을 추가하는 스크린샷](https://success.outsystems.com/TK_Resource/afbd3a67-8002-486a-85e3-3cce11271534 "Adding Index Attributes")
    
6. [**Close**]를 클릭합니다.
    
7. 모듈을 게시하여 데이터베이스에 생성한 인덱스를 적용합니다.
    
    게시 과정 중에 OutSystems에 의해 해당 데이터베이스 인덱스가 엔티티 속성에서 정의한 대로 생성됩니다.
