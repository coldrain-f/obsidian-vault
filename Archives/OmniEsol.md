CI(Common Information) 모듈:
- 그룹정보관리

MA(MAster) 모듈:
- 회사기준관리

Multi-GAAP:
- 나라마다 회계 정보가 다른데 이를 설정해서 관리할 수 있음.
	- 중국, 베트남 등

Stored Procedure 미사용
- 유지보수 과정에서 계속 수정이 이루어져서 관리가 어려워서 걷어내었음.


CI MASTER:
- 통합코드: Lsit Box에 나오는 코드
- CI 코드에 없는 코드는 그 어디서든 사용할 수 없다.
	- 필요한 코드는 CI Level의 코드에서 가져다가 사용해야 함.

Auto-Posting
- 자동으로 회계전표를 생성
- 품목, 수불유형, 오더유형의 조합
- 구매입고, 생산출고, 생산입고, 판매출고 등에서 Posting이 발생한다.
	- 설정 가능


Auto-Pricing (자동가격결정)
- 절차가 복잡하여 많이 사용하지는 않는다.
	- 수주 유형 설정에 따라서 설정

대시보드 구성
- 사용자 별, 그룹 별 위젯을 설정할 수 있음.
- 임원이 보는 대시보드, 사용자가 보는 대시 보드를 개별로 구성 가능
- 위젯마다 쿼리를 타기 때문에 대용량 데이터 쿼리 화면은 위젯 사용을 지양해야 한다.
	- 오랫동안 쿼리가 진행되면 멈춰있는 것 처럼 보일 수 있음.

- 트리 구조로 서브 메뉴가 오른쪽에 표시
