# 새로운 기능

웹 뷰어(새로운 코어 플러그인)를 통해 Obsidian 내에서 외부 링크를 열 수 있습니다. 앱을 벗어나지 않고도 연결된 콘텐츠를 읽을 수 있어 웹 리서치 시 멀티태스킹이 더욱 편리해졌습니다. 이 플러그인은 기본적으로 비활성화되어 있으며 설정에서 수동으로 활성화해야 합니다.

동기화 기능에 "내 변경사항 숨기기"라는 새로운 보기 옵션이 추가되었습니다. 이를 통해 공유된 Obsidian 동기화 보관함에서 자신의 파일 변경사항을 숨길 수 있습니다.

파일 탐색기에 현재 활성 파일을 자동으로 표시하는 옵션이 추가되었습니다.

"현재 파일의 첨부파일 다운로드" 명령이 추가되었습니다. 이 기능은 외부에 임베드된 모든 이미지를 다운로드하고 외부 링크를 내부 임베드로 대체합니다.

"각주 삽입" 명령이 추가되었습니다. 각주 자동완성 기능은 이제 일치하는 항목이 없을 경우 새 각주를 생성하는 대체 옵션을 제공합니다.

태그 보기에 검색 필터가 추가되었습니다.

개요에 "현재 섹션으로 자동 스크롤" 옵션이 추가되었습니다.

# 개선사항

* 번호가 매겨진 목록을 수정할 때 번호가 자동으로 업데이트됩니다.
* 최근 사용한 명령이 이제 명령 팔레트 상단에 표시됩니다.
* 에디터 제안이 이제 입력이 변경될 때 맨 위로 스크롤됩니다.
* 탭 앞/뒤 탐색 버튼을 마우스 중간 버튼으로 클릭하면 새 탭에서 파일이 열립니다.
* "형식" 하위 메뉴 아래의 에디터 컨텍스트 메뉴에 "주석" 옵션이 추가되었습니다.

잘못된 프론트매터가 있는 파일의 처리가 개선되었습니다:
* 읽기 모드에서 파일 상단에 오류 메시지가 표시됩니다.
* "속성 추가" 명령이 이제 잘못된 프론트매터를 제거하는 대신 오류를 표시합니다.

캔버스 관련 개선사항:
* 캔버스 그룹은 이제 빈 라벨을 가질 수 있으며, 편집 중에도 계속 표시됩니다.
* 캔버스 카드는 확대/축소되어 있어도 활발히 편집 중일 때는 마운트된 상태를 유지합니다.
* 동기화 버전 기록에서 캔버스 파일을 볼 때 미리보기 이미지가 렌더링됩니다.

기타 개선사항:
* <source> HTML 요소가 이제 상대 링크를 지원합니다.
* "현재 파일 검색" 검색창에 총 결과 수가 표시됩니다.
* 퀵 스위처에서 북마크된 URL의 렌더링이 개선되었습니다.
* 검색에서 아래쪽 화살표 키를 누르면 검색창에서 커서가 제거되어 결과를 더 쉽게 탐색할 수 있습니다.
* "템플릿 삽입" 명령이 이제 파일 경로별로 템플릿을 정렬하고 폴더 이름을 표시합니다.

# 버그 수정

* 라이브 프리뷰에서 참조 스타일 링크가 올바르게 렌더링됩니다.
* "탭 들여쓰기 크기" 설정이 이제 탭/들여쓰기의 시각적 너비를 제어합니다.
* 제목 및 블록 ID 이름 변경 시 수정된 파일 수가 잘못 표시되는 문제가 수정되었습니다.
* 그래프 보기가 더 이상 캔버스 파일을 첨부파일로 간주하지 않습니다.
* 검색 정렬 순서 기본 설정이 항상 저장되지 않는 문제가 수정되었습니다.
* Obsidian을 종료하기 전에 레이아웃 및 구성 변경사항이 항상 저장됩니다.
* 템플릿 내용이 가로 규칙으로 시작하고 커서가 파일 시작 부분에 있을 때 "템플릿 삽입"이 실패하는 드문 버그가 수정되었습니다.

PDF 관련 수정사항:
* PDF에서 텍스트 선택 시 깜박임 현상이 수정되었습니다.
* PDF 보기의 "선택 영역에 대한 링크 복사"가 때때로 잘못된 텍스트 노드에 적용되는 문제가 수정되었습니다.

기타 수정사항:
* 일본어 문자가 기본 글꼴 사용 시 잘못 렌더링되는 문제가 수정되었습니다.
* 팝업 창에서 rem 단위가 메인 창과 일치하지 않는 문제가 수정되었습니다.
* 인라인 각주가 항상 메타데이터 캐시에 의해 처리되지 않는 문제가 수정되었습니다.
* 속성 값 입력이 이제 맞춤법 검사 설정을 준수합니다.

# 개선된 사용자 경험

* 파일 탐색기에서 아무 곳이나 마우스 오른쪽 버튼으로 클릭하면 컨텍스트 메뉴가 표시됩니다.
* 파일 탐색기에 선택한 항목으로 새 폴더를 만드는 메뉴 옵션이 추가되었습니다.
* 목록 속성의 개별 값을 컨텍스트 메뉴나 Command/Ctrl + C를 사용하여 복사할 수 있습니다.
* 로컬 속성 보기에서 아무 곳이나 마우스 오른쪽 버튼으로 클릭하면 속성 메뉴가 표시됩니다.
* 파일 탐색기에서 접힌 폴더 위로 파일을 드래그하면 폴더가 자동으로 펼쳐집니다.
* 속성 메뉴에서 정렬 옵션을 사용할 수 있습니다.
* 라이브 프리뷰와 읽기 모드에서 상대 경로가 있는 `<img>, <video>, <audio>` 태그가 렌더링됩니다.
* 탭이 너무 작으면 탭 닫기 버튼이 숨겨집니다.
